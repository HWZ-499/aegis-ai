# CVE-2019-5736 Container Runtime Escape

Tags: cve-2019-5736, container, runc, runtime-escape

CVE-2019-5736 is a container runtime escape in runc where a malicious container
process could overwrite the host runc binary through `/proc/self/exe` handling.

## Agent relevance

This is not a normal source-code injection finding, but it is useful context for
reports involving container execution, unsafe host mounts, privileged
containers, or vulnerable runtime dependencies.

## Fix template

- Keep container runtimes patched.
- Avoid privileged containers and unnecessary host mounts.
- Use defense in depth: read-only root filesystems, seccomp, AppArmor/SELinux,
  user namespaces, and least-privilege runtime configuration.
