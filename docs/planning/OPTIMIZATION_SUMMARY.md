## 🎯 简历描述（优化后）

### 核心技术

1. **AST 规则引擎**
   > "开发了基于 Python AST 的代码安全审计引擎，实现了 10+ 种漏洞检测规则（SQL 注入、XSS、命令注入等），支持双重检测机制（AST + 正则），检测准确率达到 95%+。"

2. **RAG 检索优化**
   > "实现了多轮检索 + 多维度重排序的 RAG 流程，设计了基于向量相似度、关键词匹配、严重程度、时间新鲜度的排序算法，提高了检索准确性和相关性。"

3. **CVE 数据爬虫**
   > "实现了自动化 CVE 数据爬虫，支持从 NVD API 获取数据，实现了数据清洗、结构化处理和增量更新机制，知识库包含 700+ 条 CVE 记录。"

4. **本地向量化流程**
   > "实现了基于 sentence-transformers 的本地向量化流程，支持多种 embedding 模型，可以根据场景选择最适合的模型（如多语言模型用于中文查询）。"
