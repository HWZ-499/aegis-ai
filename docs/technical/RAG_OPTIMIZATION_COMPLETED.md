## 🎯 目标

将简单的单条检索（`n_results=1`）升级为：
1. **多轮检索**：检索 Top-K（5-10 条）
2. **多维度重排序**：基于相似度、关键词、严重程度、时间新鲜度
3. **上下文融合**：将多条结果合并为增强上下文
4. **去重功能**：避免重复信息
